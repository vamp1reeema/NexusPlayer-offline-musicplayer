# Nexus Player

Тёмный офлайн-музыкальный плеер для Android.

Никаких аккаунтов, интернета и рекомендаций — только твоя музыка с устройства и виниловый интерфейс.

## Возможности

- Сканирование медиатеки телефона
- Полноценный список треков с поиском
- Воспроизведение в фоне
- Управление музыкой в шторке уведомлений
- Кнопка «Назад» возвращает в список, а не закрывает приложение
- Анимированный винил (крутится при воспроизведении)
- Тёмная тема в стиле виниловой комнаты
